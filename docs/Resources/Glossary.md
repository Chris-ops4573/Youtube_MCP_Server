# Glossary

From SRS Appendix A.

- **MCP** - Model Context Protocol: lets AI clients use tools and data from a server.
- **Agent Skill** - a SKILL.md folder giving an AI a repeatable workflow.
- **ADR** - Architecture Decision Record, kept in `docs/adr/`.
- **PARA** - Projects, Areas, Resources, Archive note organisation.
- **Quota unit** - cost unit of YouTube API calls; 10,000 per day by default.
- **TF-IDF / cosine** - text weighting and a 0-1 similarity between two texts. See [[Similarity]].
- **Fixture** - recorded sample API response so tests need no live calls. See [[Providers]].
- **Proposal** - a stored, unconfirmed playlist plan with ID, hash and expiry.
- **PKCE** - extension that protects the OAuth authorisation-code flow.
