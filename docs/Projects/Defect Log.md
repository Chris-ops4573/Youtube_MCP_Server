# Defect Log

TQ-8: every defect found while building or testing is written down here with how it was found, the fix and the test that stops it coming back. Part of [[Development Plan]]. Testing in general is in [[Testing]].

Rule: **every new defect gets a row and a regression test.** If a test is not possible (for example a mistake in the environment or in how we work), the row says what was done instead.

## Known behavior, not a defect
- Writes are never retried. After a timeout a playlist might already exist, so the person proposes again ([[ADR-013 Playlist creation needs a person's confirmation]]). This narrows the SRS retry rule on purpose.
